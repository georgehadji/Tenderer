# discovery/: CONTEXT

Customer discovery for the gates in [`docs/plan.md`](../docs/plan.md) §6, starting with step 2 (interviews). The repo is public, so personal data never enters git: raw interview notes and the key from interview codes to people live in `discovery/private/`, which `.gitignore` excludes (it is not part of the repo and has no CONTEXT file). Only aggregated summaries are committed.

| File | Contains / does |
|---|---|

| `interview-log-template.csv` | Header-only template for the interview log (22 columns, described in `interviews-taxi-2026.md` §8). Copy it to `discovery/private/` before use; never commit a filled copy. |
