# tenders/pkm-meth-student-transport-dsa-2026/declarations/: CONTEXT

Draft texts of declarations (υπεύθυνες δηλώσεις), one per requirement id, rendered by `apps/documents` into the client plan with the watermark. Plain-text Django templates; the variables are `invitation`, `tender_title`, `routes` (route codes of the bid) and `resources` (the client's resources by kind, with their attributes). Only declarations without sensitive parts belong here. The wording is ours, **UNVERIFIED** against any template the invitation may prescribe: the client checks it before signing in gov.gr.

| File | Contains / does |
|---|---|
| `R9.txt` | Routes, plates, passenger seats and seat belts (§4.3.1.1). Seat belts are left as a blank for the client, because we do not record them. |
