# tests/: CONTEXT

pytest, with Hypothesis for properties and pytest-django for the database tests (run them with a local PostgreSQL, e.g. `docker compose up -d`). One file per module. Golden values come from outside the code under test: the tender, the v0 workbook check, or an independent Decimal oracle (`docs/build-plan.md` §7).

| File | Tests |
|---|---|
| `settings.py` | Test settings: the production settings with a throwaway secret and a local database without TLS (`PG*` variables; CI uses a PostgreSQL 17 service). |
| `conftest.py` | `tender` fixture: the real tender loaded with the real pack registry. `verified(client, user)` and the `admin_client` override: sign in with a verified second factor, as the OTP admin site requires. |
| `test_catalog.py` | The tender loads; version; determinism; every invalid row or field refuses the tender with its line and column. |
| `test_rules.py` | The document-freshness boundaries of the v0 workbook check (R1, R9, R12, R13, R18, R22, manual, not applicable); H3 property (no SATISFIED without its facts); deadlines (working days, roll-forward, ambiguity); every rule kind; `days360_us`. Cases found by mutation testing: every reason code, the months unit, roll-forward by one day, the working-day conventions, the unreviewed-years note, calendar files adding up. |
| `test_pricing.py` | Offer price rounding, guarantee amounts, validator errors in workbook order, groups, duplicates, floats rejected, participation-guarantee checks; property: prices are whole cents. Cases found by mutation testing: a duplicate first priority, a group with one discount, a guarantee without its kind, `to_decimal` refusals. |
| `test_taxi_costs.py` | Six routes × 100 discounts against the Decimal oracle of the workbook check; break-even including the edge route; missing inputs; warnings. The registry hook `gonogo` equals the oracle; missing inputs, floats and non-dates. |
| `test_gr.py` | Easter vectors 2026–2028, `reference/gr/` files equal the computation, number words; ΑΦΜ, plate and phone validators with synthetic values. |
| `test_lifecycle.py` | Every legal transition of every template, every other (state, event) pair refused, H7 guard cases, build-time checks. |
| `test_engagements.py` | Against PostgreSQL: validation on every save, resource schemas, database CHECKs, transitions only through `api`, the DRAFT → CHECKED guard and `reopen`, schema review for prohibited data in every app's models (AD5). |
| `test_documents.py` | Against PostgreSQL: client-plan snapshot (`snapshots/client_plan.html`); every checklist item with its requirement, status and `§`; the tender-data version; the watermark on the R9 draft; pack labels instead of codes; the never-ask line; escaping of hostile values in title, step, invitation and the declaration (template injection); no declaration read for an unsafe tender id; sending; Greek number formats; admin preview and send. |
| `snapshots/` | Golden files; see its `CONTEXT.md`. |
| `test_shell.py` | The log filter: tax ids, phones and e-mails redacted in messages and tracebacks, other numbers kept; every handler carries it. Every admin screen (index, 11 lists, 3 add forms, a change form) renders without inline script or `on*` handlers, which the Content Security Policy would block. |
| `test_audit.py` | Against PostgreSQL: UPDATE and DELETE of audit events refused by the trigger; the app role of `deploy/roles.sql` can insert and read but not update, delete or truncate; one event per transition with the correlation id and actor; audited views, the `X-Correlation-ID` and security headers; the admin refuses a password without a second factor; sign-in events without usernames; the three roles and what an operator cannot open. |
| `test_privacy.py` | Against PostgreSQL: export of every record, audited without personal data; erasure refused while an engagement is open, then complete; the retention job (refuses without N, erases expired clients, schedules ended ones, leaves active ones, idempotent); admin export and confirmed erasure. |
| `test_v0import.py` | Against PostgreSQL: a filled copy of the v0 template, with the oracle's results where the spreadsheet caches its own, imports with zero differences (6 routes, the offer, the guarantee, 24 document rows) and records bid, go/no-go, offer check, checklist, documents and deadlines; re-import changes nothing; one euro of difference rolls everything back; a file never saved by a spreadsheet is refused; a missing resource is reported; a guarantee one cent short fails R8; the command. |
| `test_alerts.py` | Against PostgreSQL: a deadline and its outbox rows commit together; each notification is sent once, a failed send is retried and never duplicated; a closed deadline sends nothing; a client without e-mail turns the dashboard red and fails the job; the heartbeat pings only while the outbox keeps up; snapshot of a reminder and the never-ask line on every e-mail (X7); `.ics` escaping and folding; admin add, dashboard and acknowledge action. Two senders never send the same row (SKIP LOCKED, with real commits). |
